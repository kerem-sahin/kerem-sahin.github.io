# kerem-sahin.github.io

My portfolio site: https://kerem-sahin.github.io

Plain HTML, CSS and JavaScript, no build step. Each app is a poster. At the end of each poster the next app's name waits in the next poster's colour; scrolling dives into one of its letters and the next poster opens in that colour. Screenshots are drawn as halftone on a canvas.

- `index.html`: the page
- `style.css`: posters, type and colours
- `harf.css`, `harf.js`: the scroll dives between posters
- `ortak.js`: app data, text fitting and the halftone renderer
